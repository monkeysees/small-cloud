# Start with disposable-data tools

The first pilot supports tools used for real recurring work whose stored data may be lost. Durable company apps are deferred so the pilot can test whether a creator can publish agent-built software without infrastructure help and colleagues return to use it, within a two-week development timebox and a $100/month infrastructure ceiling excluding labor. Pilot users must be told explicitly that data is disposable; company approval is assumed for this pilot, and company-specific environment customization remains an unvalidated requirement.

The chosen pilot workload is a shared weekly check-in board for priorities and blockers, initially using user-entered data. The scope was subsequently expanded to allow public internet access and creator-configured secrets. Platform-managed company integrations remain deferred; creator-supplied credentials require explicit decisions about authority when tools are shared.
