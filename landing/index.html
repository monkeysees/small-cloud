Small Cloud is in testing. New users are added manually.

There is no self-service signup. Access requires an administrator to add you to the workspace; publishing apps requires a separate creator grant.

App databases persist across restarts and redeployments. During testing, there is no backup or recovery guarantee, so keep important data backed up elsewhere.
