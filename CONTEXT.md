# Small Software Cloud

A cloud for purpose-built software used by one person or a small group, including colleagues sharing bespoke tools.

## Language

**Small software**:
Purpose-built software intended for one person or a small handful of users.

**Prototype**:
Small software shared to demonstrate or explore an idea.

**Tool**:
In the first customer's terminology, small software whose stored data is disposable and is not expected to survive.

**App**:
In the first customer's terminology, small software with persistent data that people rely on, potentially including company data.

**Workspace**:
The group of colleagues within which small software can be shared.

**Creator**:
The person who publishes a tool and chooses its sharing scope.

**Sharing scope**:
The audience allowed to access a tool: its creator alone or everyone in its workspace.

**Workspace administrator**:
The operator who admits workspace members, grants creator privileges, and can disable tools.

**Workspace member**:
A person explicitly admitted to the workspace who can use workspace-wide tools. Membership alone does not grant creator privileges.

**Tool secret**:
A creator-configured confidential value entrusted to a tool, such as an external service credential. Authorized users can trigger the actions the tool exposes using that value.

**Active tool**:
A deployed tool currently running and occupying one of the workspace's limited execution slots. A deployed tool can remain available to start without being active.

**Build allowance**:
The workspace's monthly allocation of build execution time, shared by all creators.
